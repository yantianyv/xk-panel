# 硬件说明

## 主板与 GPIO

| 项目 | 值 |
|---|---|
| 平台 | Intel N100（Alder Lake-N） |
| GPIO 控制器 | PCH GPIO，内核 `pinctrl` 设备 `INTC1057:00`，暴露为 `/dev/gpiochip0`（151 个已注册引脚） |
| 引脚配置寄存器 | 每个引脚 `PADCFG` 4 字节；本机型面板相关引脚被 BIOS 预配置为 GPIO 输出，特征值 `0x840002xx`（低电平点亮） |

引脚名与线号的对应关系可从 `/sys/kernel/debug/pinctrl/INTC1057:00/pins` 读取（需要 root）。程序优先读取该表，读取失败时使用内置的实测线号表。

## Super I/O（EC）

| 项目 | 值 |
|---|---|
| 芯片 | **ITE IT8613E**（Super I/O + 硬件监控） |
| 配置端口 | `0x2E` / `0x2F`（进入配置：`0x87 0x01 0x55 0x55`；退出：`0x02 0x02`） |
| 硬件监控寄存器 | 索引 `0x295` / 数据 `0x296`（bank 0，通过 `0x06` 切换 bank） |
| 风扇 PWM 通道 | PWM1 `0x15`/`0x63`、**PWM2 `0x16`/`0x6B`（本机风扇）**、PWM3 `0x17`/`0x73` |
| 风扇转速寄存器 | `0x0D`~`0x12`（16 位，需 EC 监控开启后有效） |

### PWM 控制寄存器语义（重要）

IT8613E 属于「新式自动 PWM」芯片：PWM 控制寄存器中 **bit7 = 自动模式开关**，bit6~0 是温度映射而非占空比：

```
自动模式： ctrl |= 0x80
手动模式： ctrl &= 0x7F      ← 由本程序按温度曲线接管时使用
占空比：   写入对应的 PWM_DUTY 寄存器（PWM2 为 0x6B，0 = 0%，255 = 100%）
```

> 依据 lm-sensors `it87` 驱动的 `set_pwm_enable()` 实现：`manual = temp_map & 0x7f`、`auto = temp_map | 0x80`。

**注意**：EC/BIOS 会周期性尝试收回风扇控制，因此接管时需要**定期重申手动模式**（本程序默认每 10 秒一次，见设置页「风扇」）。若出现转速异常，可通过设置页「交还 BIOS 风扇控制」恢复，或彻底断电（拔电源 10 秒）让 EC 复位。

## /dev/mem 限制

飞牛 fnOS 的内核默认启用严格 `/dev/mem` 访问限制，映射 PCH GPIO 的 MMIO 会返回 `EPERM`；如需直接读写物理寄存器（例如对照分析原厂程序），需在内核启动参数中加入 `iomem=relaxed` 并重启。

本驱动的正常运行**不需要** `/dev/mem`：指示灯通过 `gpiochip` 操作，风扇通过 `/dev/port` 的 EC 索引/数据端口操作。
