# 前面板 LCD 协议

面板控制器为 **Holtek USB-HID** 设备（`VID:PID = 374a:b101`，设备名 `USB-HID AP`）。本文记录其与主机之间的通信协议。

## 设备与端点

| 项目 | 值 |
|---|---|
| VID / PID | `0x374a` / `0xb101` |
| 设备节点 | `/dev/hidrawN`（按 VID/PID 匹配，不保证编号固定） |
| 报告描述符 | Usage Page `0xFF00`（厂商自定义），Input 64 字节、Output 64 字节、Feature 8 字节 |
| 实际数据通道 | **Feature 报告**（`HIDIOCSFEATURE` / `HIDIOCGFEATURE` 控制传输） |

> 设备暴露了 64 字节的中断 IN/OUT 端点，但官方驱动与实测均表明数据只走 Feature 报告。

## 报文格式

固定 **9 字节**，首字节为 hidraw 的报告 ID 槽位：

```
偏移   0      1      2      3        4 5 6 7        8
含义  ReportID  0   cmd    sub    data[4]        checksum
```

- `ReportID`：无编号报告，固定 `0x00`
- `checksum = (255 - sum(bytes[0..7])) & 0xFF`，即**整包 9 字节之和恒为 0xFF**

## 初始化

连接后各发送一次：

```
00 00 88 00 00 00 00 00 77
00 00 88 01 00 00 00 00 76
```

未收到数据时，屏幕自身显示 `STARTING SYSTEM / PLEASE WAIT`；收到数据后切换到运行信息界面。

## 主机 → 屏幕（数据）

| cmd | sub | data | 含义 |
|---|---|---|---|
| `0x88` | `0` / `1` | — | 初始化握手 |
| `0x03` | `1` | 1 字节 | CPU 温度（℃） |
| `0x03` | `2` | 1 字节 | 系统温度（℃） |
| `0x03` | `3`~`6` | 1 字节 | 硬盘 1~4 温度（℃） |
| `0x02` | `1` | 4 字节大端 | 存储总容量（GB） |
| `0x02` | `2` | 4 字节大端 | 可用容量（GB） |
| `0x02` | `3` | 4 字节大端 | 已用容量（GB） |
| `0x00` | `1` / `2` | 4 字节 | 网口 1 / 网口 2 的 IP 地址 |
| `0x00` | `0x81` / `0x82` | 4 字节 | 网口 1 / 网口 2 的子网掩码 |
| `0x00` | `0x41` / `0x42` | 4 字节 | 网口 1 / 网口 2 的网关 |
| `0x08` | `1` | 4 字节 | 屏幕上展示的默认 IP |

数值类字段按 1 秒节奏循环推送即可（屏幕会在收到后切换界面并保持）。

## 屏幕 → 主机（按键与状态）

同样为 9 字节 Feature 报告，读回时 `[1]` 通常为 `0x80`：

| 字节 | 含义 |
|---|---|
| `[3]` | 命令类型：`1` = 电源动作，`2` = 网络配置，`4` = USB 相关 |
| `[4]` | 子动作 |

| `[3]` | `[4]` | 含义 |
|---|---|---|
| `1` | `0` | 请求关机 |
| `1` | `1` | 请求重启 |
| `2` | — | 屏幕菜单修改了网络参数（IP / 掩码 / 网关 / DHCP） |
| `4` | `0` | 请求执行 USB 备份 |
| `4` | `1` | 请求弹出 USB 设备 |

屏幕菜单的导航（上 / 下 / 菜单 / 确认）由屏幕固件自行处理，仅在触发上述动作时才上报主机。

## 关于背光

**LCD 背光亮度不可由主机控制。**

- 官方 .NET 驱动（`HidCon.dll`）的命令集合中不存在背光/亮度命令；官方系统镜像中的应用包与常驻服务同样没有相关代码
- 实测中也确认：全量扫描 HID 命令族（含 `0x88` 全子命令）、中断 OUT 端点、键盘 LED 输出报告、EC GPIO 与 PWM 通道、PCH 全部已注册 GPIO 引脚，均无法改变背光亮度
- 结论：背光状态由屏幕自身硬件决定（属面板固件/硬件层面），主机只能推送显示数值

## 协议来源

协议通过对官方驱动 `HidCon.dll`（.NET 程序集）的 IL 反汇编获得，并在真机上逐项验证（设备会回显最近一次写入的数据，可用于确认写入生效）。相关工具见 [`tools/ildis.py`](../tools/ildis.py)。
