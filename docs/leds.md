# 面板指示灯与引脚映射

以下为本机型（兮克 TS3004E）**实测**结果。所有指示灯均为**低电平点亮**（`0` = 亮，`1` = 灭）。

> ⚠️ 原厂程序中使用的引脚命名与面板实际灯位**并不一致**（例如原厂命名为 `LAN1` 的引脚实际点亮的是下面那个网口），因此请以本表为准；若接线不同，可用设置页的校准功能重新映射。

## 状态指示灯（三原色）

| 功能 | 颜色 | 引脚名 | gpiochip 线号 | 备注 |
|---|---|---|---|---|
| 电源键灯 | 红 | `GPP_S_3` | 99 | |
| 电源键灯 | 绿 | `GPP_S_1` | 97 | |
| 电源键灯 | 蓝 | `GPPC_A_11` | 75 | 原厂程序中作为常写引脚 |
| 状态灯 | 红 | `GPP_S_4` | 100 | 电源键下方灯条 |
| 状态灯 | 绿 | `GPP_S_2` | 98 | 电源键下方灯条 |
| 状态灯 | 蓝 | `GPP_S_6` | 102 | 电源键下方灯条 |

两个三原色灯均支持软件 PWM 混色，因此可通过不同亮度组合出橙、黄、青、紫、白等颜色（状态灯与电源键灯即按此实现渐变与呼吸）。

`GPP_S_5`（线 101）实测**不点亮任何灯**，为空脚。

## 硬盘位灯（每盘位两组）

| 盘位 | 绿灯（在位） | 红灯（故障） |
|---|---|---|
| 1 | `GPP_S_0`（96） | `GPPC_D_19`（211） |
| 2 | `GPPC_H_4`（164） | `GPPC_H_5`（165） |
| 3 | `GPPC_D_3`（195） | `GPPC_H_7`（167） |
| 4 | `GPPC_D_0`（192） | `GPPC_D_1`（193） |

同一盘位的两颗灯物理上相邻，同时点亮会呈现黄色，因此驱动中保证**故障时只亮红、正常时只亮绿**。

## 其他指示灯与按键

| 功能 | 引脚名 | 线号 |
|---|---|---|
| USB 指示灯（左下） | `GPPC_A_13` | 77 |
| 网口 1 指示灯（上方网口） | `GPPC_F_7` | 295 |
| 网口 2 指示灯（下方网口） | `GPPC_B_7` | 7 |
| 复位按键 | `GPPC_B_5` | 5 |
| USB 复制按键 | `GPPC_B_6` | 6 |

> 两个按键在 BIOS 中被配置为输入（PADCFG `0x84000102`）。

## 引脚校准

设置页 →「高级」→「灯位与引脚」提供：

- **逐脚探测**：默认只遍历 LED 特征引脚（`PADCFG = 0x840002xx / 0x840001xx`，安全）；可选择「全部引脚」模式（会驱动非指示灯引脚，有风险，界面有提示）
- **功能重映射**：19 个功能位（电源键 RGB、状态灯 RGB、USB、网口 1/2、盘位 1~4 的绿/红、两个按键）均可从候选引脚重新选择并单独测试
- **恢复默认**：一键回到本机型实测映射

映射保存在应用数据目录的 `settings.json` 的 `pin_map` 字段中。
